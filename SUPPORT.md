# Getting help

| You want to | Go to |
| :-- | :-- |
| Report a reproducible bug | The repository's **Issues** tab, form **Bug report** |
| Propose a feature | **Issues**, form **Feature request** (or **Discussions** when the repository has them) |
| Ask how to use something | **Discussions**, category **Q&A**; if disabled, **Issues** with the `question` label |
| Report a vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| Fix documentation | A pull request, or the **Documentation** issue form |
| Reach the maintainers | contact@aphrody.com |

Before asking, read the repository README and `docs/`, and search closed issues. Forks (repositories that say "forked from" under the title) are mirrors of upstream projects: report upstream behavior to the upstream project.

Support is best effort by a small team and its automation; there is no response-time guarantee outside [SECURITY.md](SECURITY.md).

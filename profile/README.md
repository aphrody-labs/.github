# aphrody-labs

Zero-copy Rust + Bun native engines, UI, and AI-first tooling.

- `ay`: core engines & runtimes
- `aui`: zero-copy UI, WebGPU WGSL & AI-first docs
- `alib`: shared ABI & polyglot libraries
- `skills` / `plugins`: agent skills & Antigravity plugins
- `.github`: org-wide reusable CI workflows & `bom.toml`
- `awesome`: curated engineering & upstream catalog
